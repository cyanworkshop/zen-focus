## 🛠️ 技術架構 (Tech Stack)

- **Core Framework**: Vue 3 (Composition API / `<script setup>`)
- **Type System**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & SCSS
- **Deployment**: GitHub Actions (Automated CI/CD)

---

## 🚀 專案特點 (Key Features)

- **即時數據儀表板**：系統運作狀態、API 呼叫量與安全警報分析。
- **模組化 UI 架構**：高度解耦的組件設計，易於維護與二次開發。
- **響應式佈局**：完美適應 Desktop、Mobile 及平板設備。
